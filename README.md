### Which model was easiest to integrate and why?
The fountain was the easiest model to integrate because it had no animations and as already the right size so it didn't need to be scaled.

### What challenges did you encounter when importing models?
I had trouble with the hay model because it came in so tiny that I couldn't see it and I thought that it wasn't loading properly. 

### How did collision detection improve the realism of your scene?
It made it so that the player could no longer walk into models like the fountain or donkey which would immediately break realism. Now the objects all feel like actual solid objects rather than just stickers in space.

### If you had another hour, what feature would you add next?
I would make the donkey move around and switch between its different animations.

### What is the difference between a decorative model and an interactive model?
A decorative model is just there to look pretty and can just be placed and forgotten about, hereas an interactive model has some sort of interaction with the player and needs to be remembered in the code so that it can referenced and updated.
